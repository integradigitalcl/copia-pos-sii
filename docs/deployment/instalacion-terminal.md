## Instalación terminal (PC2) — PosEdge Multicaja

### Requisito

- El **Servidor (PC1)** ya debe estar instalado y encendido.
- Ambos equipos en la **misma red**.

### Pasos

1. En la PC que será **Terminal**, ejecutar:
   - `PosEdge-Terminal-Setup.exe`
2. Aceptar permisos de administrador si Windows lo solicita.
3. Esperar a que termine.

El instalador busca el servidor automáticamente (sin IP).

### Resultado esperado

Al finalizar debe decir: **“Terminal multicaja lista”**.

### Qué hace solo

- Detecta el servidor por red.
- Deja el terminal listo para conectarse automáticamente.
- Prepara el almacenamiento local (cache/replica).
