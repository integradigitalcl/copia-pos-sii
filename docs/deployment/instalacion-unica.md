## Instalación única (AUTO‑ROLE) — PosEdge Multicaja

### Archivo único

- Ejecutá: `PosEdge-Setup.exe`

### Qué hace automáticamente

El instalador decide el rol sin preguntarte:

- Si **no detecta** un servidor en la red → se configura como **Servidor**.
- Si **detecta** un servidor en la red → se configura como **Terminal**.

### Mensajes esperados

- “Validando instalación…”
- “Preparando servidor…” **o** “Configurando terminal…”
- “Sistema listo”

### Requisitos

- Misma red local para server y terminal.
- En la primera PC: correr el instalador y esperar.
- En la segunda PC: correr el mismo instalador.
